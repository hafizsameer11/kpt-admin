# Kipit Admin

Operations console for Kipit — users, compliance, withdrawals, products, rates, marketing, and support.

This app was split out of the consumer prototype so admin and web ship as separate projects.

## Development

```sh
bun install   # or npm i
bun run dev   # http://localhost:3001
```

Demo sign-in credentials are in `src/lib/admin-auth-flow.ts`.
